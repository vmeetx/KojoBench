<geometry>
Goal: Draw a hexagon with six semicircles attached to each side.
Canvas/scale: 500x500 pixels.
Main shapes:
- Hexagon with side length 100 pixels.
- Six semicircles, each with radius 50 pixels.
Drawing order:
1. Draw the hexagon.
2. Draw a semicircle on each side of the hexagon.
</geometry>

```scala
clear()
setSpeed(fast)

// Draw the hexagon
repeat(6) {
  forward(100)
  right(60)
}

// Draw semicircles on each side of the hexagon
penUp()
forward(50)
right(90)
penDown()

for (i <- 0 until 6) {
  left(90, 50)
  right(90, 50)
  forward(100)
  right(90, 50)
  left(90, 50)
}
```
