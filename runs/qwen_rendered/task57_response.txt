<geometry>
Goal: Draw three equilateral triangles in an equilateral arrangement.
Canvas/scale: 500x500 pixels.
Main shapes:
- Large triangle with side length 200 pixels.
- Smaller triangle with side length 100 pixels.
Drawing order:
1. Draw the first large triangle.
2. Move to a position for the smaller triangle.
3. Draw the smaller triangle.
4. Move back to the starting point of the first large triangle.
5. Draw the second large triangle.
</geometry>

```scala
clear()
setSpeed(fast)

// Draw the first large triangle
repeat(3) {
  forward(200)
  right(120)
}

// Move to a position for the smaller triangle
penUp()
forward(100)
right(60)
forward(100 * Math.sqrt(3))
left(120)
penDown()

// Draw the smaller triangle
repeat(3) {
  forward(100)
  right(120)
}

// Move back to the starting point of the first large triangle
penUp()
right(60)
forward(100 * Math.sqrt(3))
left(120)
forward(200)
penDown()

// Draw the second large triangle
repeat(3) {
  forward(200)
  right(120)
}
```
