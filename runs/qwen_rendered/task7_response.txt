<geometry>
Goal: Draw a square with a triangle attached to its right side.
Canvas/scale: 500x500 pixels.
Main shapes:
- Square with side length 100 pixels.
- Triangle with base and height both 100 pixels, pointing to the right.
Drawing order:
1. Draw the square.
2. Move to the end of the top edge of the square.
3. Draw the triangle.
</geometry>

```scala
clear()
setSpeed(fast)

// Draw the square
repeat(4) {
  forward(100)
  right(90)
}

// Move to the end of the top edge of the square
forward(100)

// Draw the triangle
right(30)
forward(100)
left(120)
forward(100)
```
