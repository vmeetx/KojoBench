<geometry>
Goal: Draw a square with four circles at each corner.
Canvas/scale: 500x500 pixels.
Main shapes:
- Square with side length 200 pixels.
- Four circles, each with radius 50 pixels.
Drawing order:
1. Draw the square.
2. Draw the circle at the top-left corner.
3. Draw the circle at the top-right corner.
4. Draw the circle at the bottom-left corner.
5. Draw the circle at the bottom-right corner.
</geometry>

```scala
clear()
setSpeed(fast)

// Draw the square
repeat(4) {
  forward(200)
  right(90)
}

// Move to the top-left corner and draw the circle
penUp()
forward(100)
left(90)
forward(100)
penDown()
right(90)
circle(50)

// Move to the top-right corner and draw the circle
penUp()
forward(200)
right(90)
forward(100)
penDown()
right(90)
circle(50)

// Move to the bottom-left corner and draw the circle
penUp()
forward(100)
left(90)
forward(200)
penDown()
right(90)
circle(50)

// Move to the bottom-right corner and draw the circle
penUp()
forward(200)
right(90)
forward(200)
penDown()
right(90)
circle(50)
```
